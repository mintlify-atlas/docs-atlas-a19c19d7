This project analyzes more than 1 million online retail transactions to predict customer repurchase probability. Starting from raw transactional data, the pipeline cleans and explores the dataset, aggregates per-customer behavioral features, labels each customer as a repurchaser or not, and then trains three binary classifiers — Logistic Regression, XGBoost, and LightGBM — evaluated by ROC-AUC.

## Dataset

The source file `online_retail_II.xlsx` contains **1,067,371 transactions** spanning December 2009 through December 2011 across transactions from 43 countries. The processed version is cached as `online_retail.pkl` for fast loading.

| Column | Type | Description |
|--------|------|-------------|
| `Invoice` | object | Invoice number (returns start with `'C'`) |
| `StockCode` | object | Product code |
| `Description` | object | Product name (0.3–0.5% null) |
| `Quantity` | int64 | Units per transaction |
| `InvoiceDate` | datetime64 | Date and time of the invoice |
| `Price` | float64 | Unit price in GBP |
| `Customer ID` | float64 | Unique customer identifier (~21–30% null) |
| `Country` | str | Customer country |

Descriptive statistics after cleaning:

## Pipeline

<Steps>
  <Step title="Load Data">
    Data is loaded from the pickled file via a custom helper to avoid re-reading the large Excel file on every run:

    ```python
    from src.extraccion import load_from_pickle

    df = load_from_pickle()
    # 1,067,371 instances × 8 attributes
    ```
  </Step>

  <Step title="Clean Data">
    Four cleaning operations are applied sequentially:

    1. **Remove exact duplicates** (34,335 rows, 3.22% of the dataset)
    2. **Remove returns** — invoices starting with `'C'` (19,104 rows) and all rows sharing those invoice IDs
    3. **Remove negative quantities and prices** — 22,496 rows with `Quantity < 0`, 5 rows with `Price < 0`
    4. **Remove incomplete countries** — `'Unspecified'` (748 rows) and `'European Community'` (60 rows)

    ```python
    # Drop duplicates
    df = df.drop_duplicates()

    # Identify and remove return invoices
    devoluciones = df[df['Invoice'].str.startswith('C', na=False)]
    df = df[~df['Invoice'].isin(devoluciones['Invoice'].unique())]

    # Remove negative values
    df = df[df['Price'] >= 0]
    df = df[df['Quantity'] > 0]

    # Remove incomplete countries
    df = df[~((df.Country == 'European Community') | (df.Country == 'Unspecified'))]
    ```
  </Step>

  <Step title="Exploratory Data Analysis">
    The notebook explores:
    - **Price and quantity distributions** — highly right-skewed; most orders are small
    - **Sales by country** — UK dominates, followed by Germany, France, and EIRE
    - **Time series** — monthly revenue computed as `df['Revenue'] = df['Quantity'] * df['Price']`, revealing seasonal peaks toward year-end
  </Step>

  <Step title="Aggregate Customer Features">
    Customers with a known `Customer ID` are aggregated into behavioral features using the `agrupar_clientes()` helper from `src/anejo.py`. The resulting per-customer DataFrame contains:

    | Feature | Description |
    |---------|-------------|
    | `Revenue_Total` | Total cumulative spend |
    | `Num_Compras` | Total number of distinct invoices |
    | `Primera_Compra` | Date of first purchase |
    | `Ultima_Compra` | Date of most recent purchase |
    | `Ticket_Medio` | Average spend per invoice |
    | `País` | Customer country |

    ```python
    from src.anejo import agrupar_clientes

    df_valid = df[df['Customer ID'].notna()].copy()
    clientes = agrupar_clientes(df_valid)
    # Total de clientes: 5,874
    ```
  </Step>

  <Step title="Build Repurchase Label">
    A cutoff date is defined at 70% of the total date range (approximately 2011-05-02). Customers present in the pre-cutoff window are features; those who also appear after the cutoff are labeled `1` (repurchaser):

    ```python
    import numpy as np

    total_seconds = (max_date - min_date).total_seconds()
    fecha_corte = min_date + pd.to_timedelta(total_seconds * 0.7, unit='s')
    # fecha_corte: 2011-05-02 01:42:30

    df_modelo = df_valid[df_valid['InvoiceDate'] <= fecha_corte].copy()
    clientes_modelo = agrupar_clientes(df_modelo)

    pseudo_recompra = df_valid[df_valid.InvoiceDate > fecha_corte]['Customer ID'].unique()
    clientes_modelo['Recompró'] = np.where(
        clientes_modelo.index.isin(pseudo_recompra), 1, 0
    )
    # Total de clientes en el modelo: 4,819
    ```
  </Step>

  <Step title="Feature Preprocessing">
    Country is one-hot encoded. Numeric features (`Revenue_Total`, `Primera_Compra`, `Ultima_Compra`, `Ticket_Medio`) are min-max scaled to [0, 1]. The train/test split uses 20% training and 80% test with 10-fold `KFold` for cross-validation:

    ```python
    from sklearn.model_selection import train_test_split, KFold

    main_kfold = KFold(10, shuffle=True, random_state=49)
    data_train, data_test = train_test_split(modelo, test_size=0.80, random_state=141)
    ```
  </Step>

  <Step title="Train Models">
    Three classifiers are trained on the customer feature matrix. Hyperparameters are tuned with **Optuna** (Bayesian optimization):

    ```python
    from sklearn.linear_model import LogisticRegression
    from xgboost import XGBClassifier
    from lightgbm import LGBMClassifier

    models = {
        "Logistic Regression": LogisticRegression(),
        "XGBoost":             XGBClassifier(),
        "LightGBM":            LGBMClassifier(),
    }
    ```
  </Step>

  <Step title="Evaluate with ROC-AUC">
    Models are evaluated using ROC-AUC on the held-out test set. All three models achieve approximately **~80% ROC-AUC**.
  </Step>
</Steps>

## Model Comparison

| Model | CV ROC-AUC | Test ROC-AUC |
|-------|------------|--------------|
| Logistic Regression | 0.774 | 0.799 |
| LightGBM | 0.788 | 0.796 |
| **XGBoost** | **0.792** | **0.801** |

XGBoost yields the highest test ROC-AUC (0.801), followed closely by LightGBM (0.796) and Logistic Regression (0.799). All three models achieve approximately **~80% ROC-AUC** on the large 80% held-out test set.

## Results

The best model — **XGBoost** — achieves approximately **80% ROC-AUC** on the held-out test set. Feature importance analysis confirms the most predictive signals across all three models:

- **`Ultima_Compra` (recency)** — customers who purchased most recently are far more likely to return (top feature in Logistic Regression and LightGBM)
- **`Num_Compras` (frequency)** — habitual buyers show higher repurchase rates (top feature in XGBoost)
- **`Revenue_Total` (total spend)** — high-value customers tend to be loyal

These findings align with classical CRM theory: recency and purchase frequency are the strongest individual predictors of future purchase behavior.
