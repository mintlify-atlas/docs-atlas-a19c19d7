This notebook applies supervised machine learning classifiers to the Wisconsin Breast Cancer dataset, exploring preprocessing steps, missing value handling, and evaluating multiple classification models to distinguish between benign and malignant tumors.

## Dataset

The Wisconsin Breast Cancer dataset (`breast-cancer.csv`) contains **699 instances** and **11 columns**. The `ID` column is dropped before modeling, leaving 9 cytological features (all scored on a scale of 1–10) plus the binary target variable `class`:

| Column | Description |
|--------|-------------|
| `clump_thickness` | Clump thickness |
| `uniformity_cell_size` | Uniformity of cell size |
| `uniformity_cell_shape` | Uniformity of cell shape |
| `marginal_adhesion` | Marginal adhesion |
| `single_epithelial_cell_size` | Single epithelial cell size |
| `bare_nuclei` | Bare nuclei *(contains 16 missing values, encoded as `?`)* |
| `bland_chromatin` | Bland chromatin |
| `normal_nucleoli` | Normal nucleoli |
| `mitoses` | Mitoses |
| `class` | Target — `2` = benign, `4` = malignant |

The dataset is read with `na_values="?"` so that `?` entries in `bare_nuclei` are automatically treated as `NaN`. The class distribution is imbalanced: **458 benign** (class=2) and **241 malignant** (class=4).

## Methodology

<Steps>
  <Step title="Load Data">
    Read `breast-cancer.csv`, mapping `?` to `NaN`:

    ```python
    import pandas as pd
    df = pd.read_csv("breast-cancer.csv", na_values="?")
    # Shape: (699, 11)
    ```
  </Step>

  <Step title="Preprocessing">
    Drop the non-predictive `ID` column, then inspect and handle missing values. Only `bare_nuclei` has missing values (16 out of 699). The notebook fills them with the mode:

    ```python
    df.drop(columns="ID", inplace=True)

    # Check missing values
    df.isna().sum()
    # bare_nuclei    16

    # Impute with mode
    df.bare_nuclei.fillna(df.bare_nuclei.mode().iloc[0], inplace=True)
    ```

    After imputation, the most frequent value for `bare_nuclei` is `1.0` (418 occurrences).
  </Step>

  <Step title="Class Balancing">
    To address the imbalance between benign (458) and malignant (241) cases, the notebook oversamples the malignant class using `sklearn.utils.resample` to reach a 40/60 ratio — a conservative choice to minimize false negatives:

    ```python
    from sklearn.utils import resample

    n_classes = df["class"].value_counts()
    classes_4_balanced = resample(
        df[df["class"] == 4],
        n_samples=(int(round(n_classes.iloc[0] * 2 / 3, 0)) - n_classes.iloc[1]),
        random_state=141
    )
    df_balanced = pd.concat([df, classes_4_balanced])
    ```
  </Step>

  <Step title="Train/Test Split and Cross-Validation Setup">
    The dataset is split 80/20 and a 10-fold `KFold` is used for hyperparameter tuning via `GridSearchCV`:

    ```python
    from sklearn.model_selection import train_test_split, GridSearchCV, KFold
    from sklearn.metrics import accuracy_score, confusion_matrix

    data_train, data_test = train_test_split(df, test_size=0.2, random_state=141)

    train_x = data_train.drop(columns="class")
    train_y = data_train["class"]
    test_x  = data_test.drop(columns="class")
    test_y  = data_test["class"]

    main_kfold = KFold(10, shuffle=True, random_state=45)
    ```
  </Step>

  <Step title="Model Training and Evaluation">
    Three classifiers are trained with `GridSearchCV` over their respective hyperparameter grids, evaluated by accuracy on the 10-fold CV splits.
  </Step>
</Steps>

## Models

The notebook trains and evaluates three scikit-learn classifiers, each tuned with `GridSearchCV`:

### K-Nearest Neighbors

The Manhattan distance metric (`p=1`) is used, and `n_neighbors` is searched over the range 1–25:

```python
import numpy as np
from sklearn.neighbors import KNeighborsClassifier

knn = KNeighborsClassifier(p=1)
param_grid = {"n_neighbors": np.arange(1, 26)}
knn_gscv = GridSearchCV(knn, param_grid, cv=main_kfold, scoring="accuracy", n_jobs=-1)
knn_gscv.fit(train_x, train_y)

predict_y = knn_gscv.predict(test_x)
accuracy_score(predict_y, test_y)   # 0.9714
```

### Random Forest

`n_estimators` is tuned across `[25, 50, 75, 100, 300]`:

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier()
param_grid = {"n_estimators": np.array([25, 50, 75, 100, 300])}
rf_gscv = GridSearchCV(rf, param_grid, cv=main_kfold, scoring="accuracy", n_jobs=-1)
rf_gscv.fit(train_x, train_y)

predict_y = rf_gscv.predict(test_x)
accuracy_score(predict_y, test_y)   # 0.9714
```

### Neural Network (Keras / TensorFlow)

A two-layer dense network is built with `tensorflow.keras` and wrapped in `scikeras.wrappers.KerasClassifier`. The number of neurons is searched over `np.arange(5, 105, step=5)`. The target labels are remapped: 2 → 0, 4 → 1:

```python
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense, Input
from tensorflow.keras.optimizers import Adam
from scikeras.wrappers import KerasClassifier

def create_model(n_neurons):
    model = Sequential()
    model.add(Input(train_x.shape[1]))
    model.add(Dense(n_neurons, activation="relu"))
    model.add(Dense(2, activation="softmax"))
    model.compile(
        optimizer=Adam(learning_rate=0.01),
        loss="sparse_categorical_crossentropy",
        metrics=["accuracy"]
    )
    return model

# Remap class labels: 2 → 0, 4 → 1
train_y.replace({2: 0, 4: 1}, inplace=True)
test_y.replace({2: 0, 4: 1}, inplace=True)

model = KerasClassifier(model=create_model, verbose=0)
param_grid = dict(model__n_neurons=np.arange(5, 105, step=5))
nn_gscv = GridSearchCV(model, param_grid, cv=main_kfold, scoring="accuracy", n_jobs=-1)
nn_gscv.fit(train_x, train_y, epochs=70, batch_size=10, verbose=0)

predict_y = nn_gscv.predict(test_x)
accuracy_score(predict_y, test_y)   # 0.9714
```

## Evaluation

All three models reach **97.14% accuracy** on the held-out test set. Confusion matrices reveal the trade-off between false positives and false negatives for each model:

| Model | True Benign (TN) | False Malignant (FP) | False Benign (FN) | True Malignant (TP) |
|-------|-----------------|----------------------|-------------------|---------------------|
| KNN | 89 | 2 | 2 | 47 |
| Random Forest | 89 | 2 | 2 | 47 |
| Neural Network | 90 | 1 | 3 | 46 |

Confusion matrix visualization:

```python
import seaborn as sns
import matplotlib.pyplot as plt

plt.show()
```
