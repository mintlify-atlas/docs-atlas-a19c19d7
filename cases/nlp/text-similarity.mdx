This notebook implements a similarity scoring function that takes two text documents and returns a similarity percentage between 0.0 and 1.0. The approach is applied to a **patent-phrase matching dataset** (36,473 training rows, 36 test rows) where each row pairs an `anchor` phrase with a `target` phrase inside a technical `context`. The continuous `score` column (ranging from 0 to 1) serves as the ground truth. TF-IDF vectorization and cosine similarity provide a lightweight, interpretable baseline for this task.

## Technique

### TF-IDF Vectorization

**TF-IDF** (Term Frequency × Inverse Document Frequency) converts raw text into a numerical vector where each dimension corresponds to a vocabulary token:

- **TF** (Term Frequency): how often a term appears in the current document.
- **IDF** (Inverse Document Frequency): a global weight that down-scales terms appearing in many documents and up-scales rare, informative terms.

The result is a sparse matrix where each row is a document and each column is a weighted vocabulary term. When two documents share many high-IDF terms, their TF-IDF vectors point in similar directions.

### Cosine Similarity

**Cosine similarity** measures the angle between two vectors regardless of their magnitude. Given two unit vectors **u** and **v**:

```
cosine_similarity(u, v) = (u · v) / (||u|| × ||v||)
```

A value of **1.0** means the vectors are identical (same direction), while **0.0** means they are orthogonal (no shared vocabulary). Negative values are possible in general, but TF-IDF vectors contain only non-negative entries, so the range in practice is [0, 1].

## Implementation

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

def similarity_rate(text1: str, text2: str) -> float:
    vectorizer = TfidfVectorizer()
    tfidf_matrix = vectorizer.fit_transform([text1, text2])
    score = cosine_similarity(tfidf_matrix[0:1], tfidf_matrix[1:2])
    return float(score[0][0])
```

The function:
1. Instantiates a fresh `TfidfVectorizer` for each call.
2. Fits and transforms both texts together so vocabulary and IDF weights are computed jointly.
3. Extracts the cosine similarity between the first and second row of the resulting matrix.
4. Returns a plain Python `float`.

## Usage Example

The notebook loads the patent dataset with `pandas` and explores its structure before applying the similarity metric:

```python
import pandas as pd

train = pd.read_csv("train.csv")
test  = pd.read_csv("test.csv")

print("train:", train.shape)   # (36473, 5)
print("test: ", test.shape)    # (36, 4)
```

The training set has columns `id`, `anchor`, `target`, `context`, and `score`. The test set is identical minus the `score` column.

Calling `similarity_rate` on a single pair:

```python
anchor  = "abatement"
target  = "abatement of pollution"
context = "A47"

score = similarity_rate(anchor, target)
print(f"Similarity: {score:.4f}")   # e.g. 0.7071
```

**Interpreting the output:**

| Score | Meaning |
|---|---|
| `0.0` | Completely different texts — no shared vocabulary |
| `0.5` | Moderate overlap — some shared terms |
| `1.0` | Identical texts — same vocabulary and proportions |

In the patent dataset, scores between 0.5 and 1.0 indicate that the anchor and target phrases describe the same or very similar concepts within the given technological context (CPC section code).

## Applications

TF-IDF cosine similarity is a practical first-pass tool for many real-world NLP tasks:

- **Plagiarism detection** — flag documents with suspiciously high overlap.
- **Document deduplication** — collapse near-identical records in large corpora.
- **Recommendation systems** — surface items whose descriptions closely match a user query.
- **FAQ matching** — route incoming questions to the most semantically similar existing answer.
- **Patent analysis** — identify overlapping claims between patent filings (the primary use case in this notebook).
