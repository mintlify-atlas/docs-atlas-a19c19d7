This notebook performs a complete NLP analysis pipeline on reviews of **fixauto.com**, a nationwide car-repair workshop network, scraped from Trustpilot. The pipeline spans data cleaning, global sentiment scoring with a HuggingFace transformer model, unsupervised topic discovery with BERTopic, per-topic sentiment breakdown, and a competitive benchmarking comparison against 44 other companies in the **Vehicles & Transportation** category.

## Objectives

1. Data extraction and cleaning
2. Global sentiment analysis
3. Topic discovery (BERTopic / LDA)
4. Per-topic sentiment measurement
5. Competitor benchmarking within the same category
6. Conclusions

## Topic Modeling

BERTopic is chosen over classical LDA because it produces more coherent topics at small corpus sizes and leverages pre-trained semantic embeddings. The workflow is:

1. Encode all reviews with a sentence-transformer model.
2. Reduce dimensionality with UMAP.
3. Cluster with HDBSCAN.
4. Extract top-12 keywords per cluster using c-TF-IDF to represent each topic.

The `N_TOPICS = 8` setting limits discovery to the eight most populated topic clusters, with any cluster containing fewer than `MIN_TOPIC_DOCS = 10` documents excluded.

```python
from bertopic import BERTopic
from sklearn.feature_extraction.text import CountVectorizer

vectorizer_model = CountVectorizer(stop_words="english")
topic_model = BERTopic(
    nr_topics=N_TOPICS,
    top_n_words=TOP_WORDS,
    min_topic_size=MIN_TOPIC_DOCS,
    vectorizer_model=vectorizer_model,
)

topics, probs = topic_model.fit_transform(df_empresa["review"].tolist())
```
