This guide walks you through everything you need to go from zero to running a complete data science notebook end-to-end. By the end you will have the repository on your machine, a clean virtual environment with all core dependencies installed, Jupyter running in your browser, and the breast-cancer classification notebook fully executed.

<Steps>

  <Step title="Clone the repository">
    Download the full project to your local machine with Git:

    ```bash
    git clone https://github.com/Programming-cases/Data-Science-and-Analytics.git
    cd Data-Science-and-Analytics
    ```

    The repository contains all notebooks, CSV datasets, and supporting source files needed to run each case study.
  </Step>

  <Step title="Create a virtual environment">
    Isolate the project's dependencies from your system Python by creating a dedicated virtual environment:

    ```bash
    python -m venv .venv
    ```

    Then activate it for your operating system:

    <CodeGroup>

    ```bash macOS / Linux
    source .venv/bin/activate
    ```

    ```bash Windows (Command Prompt)
    .venv\Scripts\activate.bat
    ```

    ```bash Windows (PowerShell)
    .venv\Scripts\Activate.ps1
    ```

    </CodeGroup>

    Once activated your terminal prompt will show `(.venv)` to confirm you are working inside the environment.
  </Step>

  <Step title="Install core dependencies">
    Install the libraries used across the notebook case studies in one command:

    ```bash
    pip install jupyter pandas numpy scikit-learn matplotlib seaborn xgboost lightgbm nltk tensorflow scikeras
    ```

    This covers data manipulation (`pandas`, `numpy`), machine learning (`scikit-learn`, `xgboost`, `lightgbm`), visualisation (`matplotlib`, `seaborn`), natural-language processing (`nltk`), and deep-learning (`tensorflow`, `scikeras`). Individual case studies may list additional requirements — check the `README.md` inside each project sub-folder for details.
  </Step>

  <Step title="Launch Jupyter">
    Start the Jupyter Notebook server from the repository root:

    ```bash
    jupyter notebook
    ```

    Jupyter will open automatically in your default browser at `http://localhost:8888`. From the file-browser interface you can navigate into any case study folder and open its `.ipynb` file. Root-level notebooks (like `Breast cancer.ipynb`) are visible immediately on the home screen.
  </Step>

  <Step title="Run a notebook">
    As your first case study, open **`Breast cancer.ipynb`**. It is a self-contained classification walkthrough that loads the Wisconsin Breast Cancer dataset, performs exploratory analysis, and builds a predictive model — no extra configuration or external services required.

    Open the file at the path below from the Jupyter home screen:

    ```
    Breast cancer.ipynb
    ```

    Once the notebook is open, run all cells in order via **Kernel → Restart & Run All**. The notebook uses `pandas`, `matplotlib`, `numpy`, `seaborn`, `scikit-learn`, `tensorflow`, and `scikeras`, all of which were installed in Step 3.
  </Step>

</Steps>

<Note>
  The **Barcelona Accidents** SQL case study (`Accidentes de tránsito en
  Barcelona/`) requires a running **MySQL 8.0+** server that is installed and
  configured separately. Before executing any of its Python scripts, make sure
  MySQL is running and update the connection credentials (`host`, `user`,
  `password`) in each `.py` file. See the project's `README.md` for the full
  setup walkthrough.
</Note>
