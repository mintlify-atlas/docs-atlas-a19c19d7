This project is a portfolio of standalone Python and Jupyter Notebook case studies that walk through real-world data problems from raw data to actionable insight. Each study is self-contained and spans one of four core domains: **NLP & Text Analysis**, **Machine Learning**, **Exploratory Data Analysis**, and **SQL & Data Engineering**. Whether you're exploring hotel-review sentiment, predicting customer repurchase probability, analysing Barcelona's climate, or building a full MySQL pipeline for traffic-accident data, every case study follows a reproducible workflow you can run on your own machine.

## Repository Structure

The repository groups case studies by the complexity of their setup. Lightweight, notebook-only studies (such as `Breast cancer.ipynb` or `Clima de Barcelona.ipynb`) sit at the root of the repository so they can be opened and run immediately. More involved projects that require supporting source files, helper modules, or external services live in their own named sub-folders, each containing a `README.md` that explains the project goals and how to run it.

```
Data-Science-and-Analytics/
│
├── 📓 Breast cancer.ipynb                    # ML — classification
├── 📓 Clima de Barcelona.ipynb               # EDA — climate analysis
├── 📓 Analisis de sentimientos.ipynb         # NLP — sentiment analysis
├── 📓 Analisis de reseñas.ipynb              # NLP — review analysis + BERTopic
├── 📓 Fake News.ipynb                        # NLP — word-frequency analysis
├── 📓 Similarity rate between two texts.ipynb # NLP — text similarity
├── 📓 Damavis.ipynb                          # EDA — technical challenge
├── 📓 Leo Messi.ipynb                        # EDA — career statistics
├── 📓 Oxfam .ipynb                           # EDA — survey data
│
├── 📂 Estudio de recompra/                   # ML — repurchase prediction
│   ├── Analisis.ipynb
│   ├── src/                                  # Helper modules
│   └── README.md
│
├── 📂 House price prediction model/          # ML — regression
│   ├── Pre-processing and feature engineering.ipynb
│   └── Supervised methods.ipynb
│
├── 📂 Accidentes de tránsito en Barcelona/   # SQL — full pipeline
│   ├── 01_schema.py … 05_analysis_queries.py
│   ├── Archivos/                             # CSV source data
│   ├── run_all.bat
│   └── README.md
│
└── 📂 Zara/                                  # EDA — stock analysis
    └── Zara.ipynb
```

## Tech Stack

| Layer | Technology |
|---|---|
| **Language** | Python 3.12 |
| **Notebooks** | Jupyter Notebook |
| **Data manipulation** | pandas 2.0, NumPy |
| **Machine learning** | scikit-learn, XGBoost, LightGBM, Optuna |
| **NLP** | NLTK, BERTopic, Hugging Face Transformers |
| **Database** | MySQL 8.0, mysql-connector-python |
| **Visualisation** | matplotlib, seaborn |
| **Other** | warnings, datetime, scipy |

<Note>
  Case studies are written in **Spanish or English** depending on the origin of
  the dataset and its intended audience. For example, the Barcelona traffic
  accidents project (`Accidentes de tránsito en Barcelona`) and the climate
  analysis (`Clima de Barcelona`) are documented in Spanish, while notebooks
  such as `Fake News.ipynb` and `Similarity rate between two texts.ipynb` are
  written in English.
</Note>
